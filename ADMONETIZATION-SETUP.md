# Monetization readiness

This is a browser game. AdMob requires an Android/iOS app with a supported SDK; it cannot simply be added to GitHub Pages.

Planned placements: banners on menus (not over the board), optional rewarded ads, and capped interstitials between levels. Ads remain disabled.

The new bonuses are a browser-local prototype, not tamper-proof. Before a real-money economy, enforce coin grants, event progress, cooldowns and daily rewards on an authenticated backend.
