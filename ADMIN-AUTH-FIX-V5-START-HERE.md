# V5 — Admin Dashboard login fix (Roman Urdu)

**Aapka Firebase login successful ho sakta hai, lekin admin authorization alag backend check hai.**

## Is ZIP mein kya fix hua
- Galat generic 403 error hataya: server ka real reason display hota hai.
- `/api/auth/status` protected diagnostic check add hua: `isAdmin`, `configuredAdminCount`, backend `version`, and last 6 characters of the signed-in UID. No secret or full admin allowlist is returned.
- `ADMIN_UIDS` parser plain UID, comma/newline UID list aur JSON string array ko handle karta hai; accidental surrounding quotes aur invisible spaces remove karta hai.
- Actual backend code changed: GitHub par commit karne se new Prisma Compute version build/deploy ho sakta hai.
- Existing game, coins, sound, mobile layout, database schema and Firebase secrets untouched.

## Aap kya karein
1. ZIP **extract** karein. Repo `sarfoCraft/sugar-rush-adventure` ke root mein files **replace** karein. Sirf ZIP upload na karein.
2. Confirm karein `.github/workflows/prisma-deploy.yml`, `backend/admin-auth.js`, `backend/server.js`, aur `index.html` GitHub mein hon.
3. **Commit to main**, phir GitHub Actions -> Prisma Deploy mein latest **green** run dekhein. Prisma Overview -> Apps mein latest deploy bhi verify karein.
4. Browser mein `https://YOUR-ACTUAL-PRISMA-API/health` open karein. JSON mein **`"version":"admin-access-fix-v5"`** zaroor aana chahiye. Agar version nahi hai, purana backend abhi chal raha hai.
5. Game `https://sarfocraft.github.io/sugar-rush-adventure/` khol kar **Ctrl + Shift + R** karein. Profile -> Admin login / connection setup click karein.
6. Agar error hai to ab woh exact problem batayega:
   - **ZERO admin UIDs**: `ADMIN_UIDS` production env runtime mein nahin aa raha. Prisma Environment mein edit + new deploy karein.
   - **N admin UID(s), but login does not match**: Firebase Authentication -> Users se **UID** check karein (email nahi). Existing `ADMIN_UIDS` Production value update karein, phir new Prisma deployment karein.
   - **Old API**: latest backend deploy nahin hua ya browser mein old build hai.
   - **401 / project issue**: Web Firebase project aur server service account ka project match check karein.

## Security
- Never paste Firebase service-account JSON, database passwords, or credentials in GitHub or chat.
- Frontend settings cannot authorize admins; only verified Firebase UID on the server can do so.
- No account bypass, public admin bootstrap, or universal master password has been added.
- Prisma's `COMPOSER_*` variables are generated by deployment; don't edit them by hand.

## Limitations
Tests here validate code and expected response flows, **not your private Prisma environment**. The real `ADMIN_UIDS` value is write-only and cannot be verified from this ZIP alone. Use the diagnostics after deployment to pinpoint whether the runtime is receiving it.
